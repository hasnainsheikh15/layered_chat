## 🚀 What is Layered Chat?

Layered Chat is a real-time messaging platform built to explore how modern communication systems work under the hood while introducing a unique concept:

### Hidden Layers

Users can embed secondary encrypted content inside normal-looking messages.

A message can contain:

```text
Visible Message:
"See you tomorrow."

Hidden Layer:
"The meeting location changed."
```

Only users who have Layer Mode enabled can discover and reveal hidden content.

This creates a messaging experience that goes beyond traditional chat applications.

# 🧠 Why This Project Exists

Most chat applications built for learning stop at:

```text
Register
Login
Send Message
```

Layered Chat explores:

* Realtime communication
* Presence systems
* Message delivery workflows
* Read receipt synchronization
* Hidden communication layers
* Session based security
* Scalable backend architecture

The goal is not just to build a chat application.

The goal is to understand how modern messaging platforms are engineered.
